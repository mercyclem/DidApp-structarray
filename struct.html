Guida Pratica alle Variabili Record (Struct)

Mentre le variabili semplici (es. int, string) contengono un singolo valore, una **Struct** permette di raggruppare più informazioni correlate in un'unica entità custom.

Avvia Simulazione Memoria Mettiti alla prova

1. Cos'è un Tipo Record (Struct)?

Contatto in Rubrica

Contiene nome, cognome, numero di telefono, e-mail. Più informazioni distinte per una sola persona.

Cartella Paziente

Numero caso, genere, età, altezza e peso. Dati di tipo diverso (int, float, string) uniti.

Prodotto in Magazzino

Codice a barre, descrizione, quantità disponibile e prezzo unitario.

Dichiarazione della Struct

Definiamo il nuovo tipo di dato T_PERSONA specificando i suoi campi interni:

struct T_PERSONA {
    string cognome;
    string nome;
    int eta;
}; // Ricorda il punto e virgola finale!

Creazione e Accesso ai Campi

Creiamo le variabili io e tu e usiamo l'**operatore punto (`.`)** per accedere ai singoli campi:

// Dichiarazione variabili record
T_PERSONA io;
T_PERSONA tu;

// Accesso campo per campo: variabile.campo
io.cognome = "Rossi";
tu.eta = 18;

3. Confronto Operazioni di Assegnazione

Esistono due modi equivalenti per copiare i dati da un record all'altro.

Metodo Consigliato

Per Intero Blocco

Copia automaticamente tutti i campi della struct in un'unica istruzione veloce.

tu = io;

Cosa succede dietro le quinte: Il compilatore C++ effettua una copia bit a bit di tutti i campi compresi nella struct.

Campo per Campo

Assegna singolarmente ciascuna informazione accedendo ai campi con il punto.

tu.nome = io.nome;
tu.cognome = io.cognome;
tu.eta = io.eta;

Nota: Produce lo stesso risultato dell'assegnazione per blocco, ma richiede più righe di codice.
