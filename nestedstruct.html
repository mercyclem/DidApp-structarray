Strutture Annidate e Vettori Paralleli in C++

In questa lezione analizziamo come rappresentare dati complessi e strutturati in C++. Utilizziamo un tipo di dato utente per rappresentare una Data annidato all'interno di una struttura Fattura, combinando variabili semplici, struct e vettori paralleli per gestire i prodotti della fattura.

Definizione delle Strutture (Dalla Foto 1)

C++ Syntax

Osserva la relazione tra T_DATA e T_FATTURA. La data non è composta da tre int sparsi, ma da una sotto-struttura riutilizzabile. 

// Costante per la dimensione massima dei vettori
const int NMAX = 100;

// 1. Sotto-struttura per la data
struct T_DATA {
    int gg; // Giorno
    int mm; // Mese
    int aa; // Anno
};

// 2. Struttura principale della Fattura
struct T_FATTURA {
    int nf;           // Numero Fattura
    T_DATA date;      // Sotto-struttura annidata!
    string Cogn;      // Cognome destinatario
    string Nom;       // Nome destinatario
    
    // Vettori Paralleli per gli articoli acquistati
    string NP[NMAX];  // Nome Prodotto
    float PP[NMAX];   // Prezzo Prodotto
    int QP[NMAX];     // Quantità Prodotto
    
    int np;           // Numero Effettivo di Prodotti presenti
};
Nota chiave: Il campo np rappresenta quanti elementi sono effettivamente utilizzati nei tre vettori paralleli, evitando di dover scorrere sempre tutti e NMAX gli elementi!

Accesso ai Campi Annidati

Per accedere ad un membro all'interno di una sotto-struttura si usa l'operatore punto . a cascata:

Esempio T_FATTURA f;
f.date.gg = 15; // Accede al giorno
f.date.mm = 10; // Accede al mese
f.date.aa = 2024; // Accede all'anno

Concetto di Vettori Paralleli

Tre vettori si dicono paralleli quando l'elemento alla medesima posizione i si riferisce alla stessa entità (stesso prodotto):

Indice (i) NP[i] (Nome) PP[i] (Prezzo) QP[i] (Quantità)
0 "Pane" 2.50 € 3
1 "Latte" 1.20 € 2
2 "Caffè" 4.50 € 1

Foto 2 Funzione CalcImp (Calcolo Importo)

Calcola il totale da pagare moltiplicando il prezzo unitario per la quantità per ogni prodotto e accumulando il totale. 

float CalcImp(T_FATTURA a) {
    float SOM;
    int i;
    
    SOM = 0;
    for(i = 0; i < a.np; i++) {
        // Accumulo: Prezzo * Quantità per l'articolo i
        SOM = SOM + (a.PP[i] * a.QP[i]);
    }
    
    return SOM;
}

Foto 3 Funzione stampaF (Visualizzazione)

Stampa il numero fattura, il destinatario, la data (accedendo a a.date.gg ecc.) e richiama CalcImp per stampare l'importo totale. 

void stampaF(T_FATTURA a) {
    float S;
    S = CalcImp(a); // Calcola prima l'importo totale
    
    cout << "DATI:" << endl;
    cout << "NUMERO:\t" << a.nf << endl;
    cout << "DESTINATARIO:\t" << a.Cogn << " " << a.Nom << endl;
    cout << "DATA:\t" << a.date.gg << "/" << a.date.mm << "/" << a.date.aa << endl;
    cout << "IMPORTO:\t" << S << endl;
}
