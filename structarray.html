Vettori nelle Struct in C++

Una struct (struttura) è un tipo di dato personalizzato che raggruppa elementi di tipo diverso sotto un unico nome. Quando inseriamo un vettore dentro una struct, possiamo rappresentare entità complesse che contengono liste o collezioni di dati omogenei.

Caso 1: Vettore Singolo (`T_ALUNNO`)

Un singolo vettore all'interno della struct serve a contenere una serie di valori associati all'entità. Un classico attributo contatore (es. nv) tiene traccia degli elementi effettivamente utilizzati rispetto al massimo (NMAX).

  • Dati anagrafici individuali (Codice, Cognome, Nome)
  • Un array interno di voti scolastici
  • Dimensione dinamica logica tramite nv

Caso 2: Vettori Paralleli (`T_FATTURA`)

Più vettori all'interno della stessa struct di pari dimensione massima. L'elemento in posizione i del primo vettore si riferisce all'elemento in posizione i degli altri vettori.

  • NP[i]: Nome del prodotto i-esimo
  • PP[i]: Prezzo unitario del prodotto i-esimo
  • QP[i]: Quantità acquistata del prodotto i-esimo
  • np: Numero di prodotti correnti nella fattura
Struttura T_ALUNNO (Dalla Lavagna - Foto 1) Vettore Singolo 
#define NMAX 20

struct T_ALUNNO {
    int cod;             // Codice univoco studente
    string Cogn;         // Cognome
    string Nome;         // Nome
    int voti[NMAX];      // Vettore fisso di voti (max 20)
    int nv;              // Numero di voti effettivi inseriti
};
Spiegazione Campi:
  • cod, Cogn, Nome: Campi singoli anagrafici.
  • voti: Array di interi dimensionato a NMAX (20).
  • nv: Intero che indica quanti elementi del vettore voti sono validi (da 0 a NMAX).
Struttura T_FATTURA (Dalla Lavagna - Foto 5) Vettori Paralleli 
#define NMAX 20

struct T_FATTURA {
    int nf;              // Numero fattura
    string Cogn;         // Cognome cliente
    string Nome;         // Nome cliente
    string NP[NMAX];     // Vettore Nomi Prodotti
    float PP[NMAX];      // Vettore Prezzi Prodotti
    int QP[NMAX];        // Vettore Quantità Prodotti
    int np;              // Numero effettivo di prodotti
};
Spiegazione Vettori Paralleli:

Per ogni generico indice i (da 0 a np-1), la combinazione NP[i], PP[i] e QP[i] descrive completamente l'articolo i-esimo inserito in fattura.

Simulatore Input Utente (cin >>)

// Codice C++ eseguito (con controlli do-while)
void Riempi(T_ALUNNO &e) {
    int i;
    // Controllo validità Codice (>0)
    do {
        cout << "Codice: ";
        cin >> e.cod;
    } while(e.cod <= 0);

    cout << "Cognome: "; cin >> e.Cogn;
    cout << "Nome: ";    cin >> e.Nome;

    // Controllo numero voti (0 < e.nv <= NMAX)
    do {
        cout << "Numero Voti: ";
        cin >> e.nv;
    } while(e.nv <= 0 || e.nv > NMAX);

    // Ciclo di caricamento del vettore voti
    for(i = 0; i < e.nv; i++) {
        cout << "Voto: ";
        do {
            cin >> e.voti[i];
        } while(e.voti[i] < 0 || e.voti[i] > 10);
    }
}

// Codice C++ CalcMedia (Foto 3)
float CalcMedia(T_ALUNNO e) {
    int S, i;
    float M;
    S = 0;
    for(i = 0; i < e.nv; i++) {
        S = S + e.voti[i];
    }
    M = (float)S / e.nv;
    return M;
}
